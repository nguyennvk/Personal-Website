Deep dives

How three pieces of my work are built: the problem, the architecture, and the trade-offs.

The problem

Users could only send text. Adding photos and voice notes meant handling large, slow uploads on mobile networks, without turning our Node server into a media proxy and without trusting whatever metadata the client sent.

Key decisions

  • Direct-to-cloud uploads. Clients upload straight to Cloudinary with server-signed parameters, so full files never pass through our API.
  • Verify, don't trust. The backend checks the upload receipt before it creates a message, so a client can't attach arbitrary URLs.
  • Designed for failure. Upload progress, error states, and retry make slow or dropped connections recoverable.

76 tests across backend and frontend · I proposed, built, and shipped it end to end

The problem

CSC258 students struggle to picture how instructions move through a pipelined CPU. Ripes is a great simulator, but it's a desktop GUI app, and we needed its output on the web for hundreds of students.

Key decisions

  • Run the GUI headless. xvfb-run gives Ripes a virtual display so it can run as a server process behind Django.
  • Normalize to JSON. The backend parses cycle, pipeline, and register output into a structured trace that the frontend can step through.
  • Grounded AI tutor. RAG over course material keeps the chatbot's answers and generated quizzes tied to what the course actually teaches.

200+ students 1,000+ runs >90% AI correctness

The problem

With 1,300+ tables and many Airflow pipelines owned by different teams, bad data was often caught late, and finding where it came from meant tracing dependencies by hand.

Key decisions

  • Checks inside the pipeline. Python/SQL validations run as Airflow tasks, so problems surface when data lands instead of in downstream reports.
  • Lineage-first debugging. DataHub lineage turns "which upstream table broke?" into a graph lookup.
  • Automate the busywork. GraphQL scripts handle metadata and permission updates for about seven teams.

~60% faster RCA ~20% lower latency 100+ hrs/yr saved
